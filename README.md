# 🏏 IPL 2025 Auction Data Analysis (EDA)

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the IPL 2025 Auction dataset using Python. The objective is to analyze player auction prices, team spending patterns, player roles, and identify valuable insights through data visualization.

---

## 🎯 Objectives

- Clean and preprocess the dataset
- Explore player auction prices
- Analyze team-wise spending
- Study player role distribution
- Identify top expensive players
- Visualize important trends using charts
- Generate meaningful business insights

---

## 📂 Dataset

Dataset Name:

**ipl_2025_auction_players.csv**

The dataset contains information about:

- Player Name
- Team
- Role
- Base Price
- Sold Price
- Nationality
- Other auction-related information

```bash

```

2. Install required libraries

```bash

```

